# Architecture Decision Records

ADRs record durable decisions and consequences. The append-only index is DECISIONS.md. To change an accepted decision, add a new ADR, mark the old ADR superseded, and update the index and affected source-of-truth documents.

Status values: `Proposed`, `Accepted`, `Deprecated`, `Superseded`.
