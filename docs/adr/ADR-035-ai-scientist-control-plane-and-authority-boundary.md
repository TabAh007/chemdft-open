# ADR-035: AI Scientist Control Plane and Scientific Authority Boundary

## Context
Phase 8 introduces ChemDFT's first interactive AI Scientist. Computational chemistry workflows require planning multi-step tasks, retrieving structures, inspecting calculations, and comparing extracted evidence against experimental datasets. However, LLMs are stochastic text generators susceptible to hallucination, sycophancy, and prompt injection. Allowing an LLM to author authoritative scientific records, create calculation results, or determine provenance state would destroy reproducibility and scientific trust.

## Decision
1. **Control Plane Only**: The AI Scientist functions exclusively as an orchestration, explanation, and synthesis control plane. It is prohibited from directly authoring authoritative scientific results (`CALCULATED`, `EXPERIMENTAL`, `EXTRACTED`, `DIGITIZED`).
2. **Result Firewall Immutability**: All calculations requested by the AI must execute via the Compute Gateway, parse through pinned engine adapters, and validate deterministically through the Scientific Result Firewall before publishing into domain storage. The model cannot bypass the firewall.
3. **Strict Domain Separation**: The model cannot create or mutate verification state (`UNVERIFIED`, `VERIFIED`, `REJECTED`), assign trusted producer identities, or alter compute costs. Hypotheses generated by the model are tagged and presented strictly as `AI_HYPOTHESIS`.
4. **Tool-Mediated Interaction**: The model communicates only through the typed Tool Registry. Direct access to SQL databases, object storage, Modal, PySCF, or OS subprocesses is forbidden.

## Consequences
- **Positive**: Scientific integrity is preserved. Even in the event of model compromise or hallucination, authoritative records cannot be forged.
- **Negative**: The model cannot perform in-memory "quick calculations" or synthesize unverified spectral points without invoking formal application tools.
