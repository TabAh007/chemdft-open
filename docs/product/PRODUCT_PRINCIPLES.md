# Product Principles

These principles resolve product tradeoffs. They are ordered; an earlier principle wins when two conflict.

1. **AI-first, never AI-only.** Language is the easiest path through multi-step work; every important operation remains directly controllable.
2. **Scientific truth before convenience.** Uncertainty, nonconvergence, unsupported methods, and missing evidence remain visible.
3. **Calculated means calculated.** Only validated deterministic engines or import pipelines create authoritative results.
4. **Preserve originals.** Scientific edits create versions/variants; experimental processing creates derived datasets.
5. **Provenance everywhere.** Any important value can answer “why am I seeing this?” with a trace to source, method, input, job, and artifact.
6. **Expert control is never removed.** Recommendations reduce setup work but never hide or lock real parameters.
7. **Disclose complexity progressively.** Default views optimize comprehension; Advanced exposes the complete relevant scientific contract.
8. **Expensive actions are transparent.** Estimates, caps, approval, consumption, cancellation, and partial completion are explicit and server-enforced.
9. **Visualization is deterministic.** Presentation may clarify data but cannot alter or invent chemistry, spectra, surfaces, or motion.
10. **One action system, many interfaces.** UI, AI Scientist, command palette, API, WebMCP, and MCP converge on the same typed domain actions.
11. **Research context persists.** Projects retain versions, evidence, decisions, corrections, failed attempts, and reproducibility context.
12. **No generic AI-SaaS slop.** Scientific hierarchy, direct manipulation, precise typography, and useful density outrank decorative cards or AI theatrics.
